# migpt

Vocabulario para construir y comprender un modelo de lenguaje que predice el siguiente token.

## Lenguaje

**Token**:
Unidad de texto que el modelo trata como un símbolo. En el primer ejercicio, cada carácter es un token.

**Vocabulario**:
Conjunto de tokens distintos que el modelo puede representar.

**Contexto**:
Secuencia de tokens disponibles para predecir el siguiente token.

**Modelo de bigramas**:
Modelo que asigna probabilidades al siguiente token usando solo el token inmediatamente anterior.

**Generación**:
Construcción de una secuencia mediante predicciones sucesivas del siguiente token.
_Evitar_: entrenamiento, como sinónimo de generación.
